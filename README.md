📝 DoItDom — Vanilla JS Todo App

A sleek, modern, and lightweight **Todo Application** built using pure **HTML5, CSS3, and JavaScript DOM Manipulation**. 

This project demonstrates core JavaScript concepts, event handling, and dynamic UI manipulation without using any external libraries or frameworks like React or Vue.

---

### 🔥 Key Features
* ⚡ **Pure DOM Manipulation:** Dynamically create, append, and remove HTML elements.
* 🎯 **Task Management:** Add new tasks, mark tasks as complete with dynamic CSS toggle, and delete unwanted tasks.
* ⌨️ **Keyboard Support:** Add tasks instantly using the `Enter` key.
* 🎨 **Clean & Responsive UI:** Minimal design styled with modern CSS.
* 🚀 **Zero Dependencies:** Pure Vanilla JS — extremely fast and fast-loading.
